---
title: Cannot Access My Project
description: Fix issues accessing your documentation project.
---

## Symptoms

- 404 error when opening project
- "Project not found" message

## Possible causes

- Incorrect project URL
- Insufficient user permissions

## Quick Fix

<Steps>
  <Step title="Check the URL">
    ````
    Make sure the project slug matches the one in your dashboard.
    ````
  </Step>
  <Step title="Verify Permissions">
    ````
    Ensure you're logged in to the correct Hamid Raza account.
    Ask an admin for access if needed.
    ````
  </Step>
</Steps>
