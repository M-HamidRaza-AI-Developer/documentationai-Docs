## Overview

To begin, create a new project space and add your documentation files.

## Steps

1. Login at `https://docs.hamidraza.com`
2. Click "New Project"
3. Enter project name & description
4. Use the editor to add content files
5. Click "Publish" to make docs live

## Example Project Structure

```
/project-name
  /docs
    getting-started.md
    introduction.md
  changelog.md
```
